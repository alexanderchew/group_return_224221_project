## Risk register

| Risk | Consequence | Required response/evidence |
| --- | --- | --- |
| Unknown contest rules | A working API wrapper or small classifier may fail the rubric | Confirm Q01; show actual trainable contribution, data and held-out evidence |
| Ten-hour capture, calls, screen lock, OS kill, disk/battery exhaustion | Recording loss or misleading reliability claim | Native feasibility probe early; durable checkpoints; real-time endurance and interruption runs; web limitation labels |
| Tiny/leaky data, teacher/source memorization, code-switching mismatch | Inflated scores with poor real performance | Group/source splits, hidden metadata, language/teacher slices, baselines and independent recordings |
| Wrong subject prediction | Wrong generation framing | Raw transcript remains canonical; confidence/abstention and manual override; no forced syllabus assumptions |
| “Meta”/question quality unspecified | Plausible outputs that do not help study | Adopt schemas and expert review; citations, answer-key validity and content limits |
| Silence trimming/denoising removes quiet teaching | Missing concepts, invalid timestamps | Keep originals, A/B evaluation, VAD padding, explicit transform maps |
| Provider limits, timeout, ambiguous billing or outage | Duplicate work or spending beyond the managed US$20 allowance | Persist stage/job/provider IDs and atomic ledger reservations; retain uncertain amounts, reconcile before retries; saved labeled backup |
| Anonymous public endpoints or exposed links | Data disclosure and uncontrolled spending | Private demo, capabilities, ownership checks, secure storage and byte/minute/token limits |
| Browser/framework/latest-runtime compatibility assumed from docs | iPhone/Android build or TensorFlow install fails despite a “latest” version label | Resolve latest stable compatible set, pin it and name actual tested device/OS/browser/build and supported recording modes |
| Laptop sleeps, disconnects or fills its disk | Local service unavailable and jobs/uploads interrupted | Probe host resources and LAN, configure demo power/network behavior, persist checkpoints/ledger and preserve client capture for reconnect |
| Team parallelism without contracts | Mismatched UI/API, styling breaks flows | Freeze shared schema/fixtures, one integration lead and recurring end-to-end merge checks |
| Deadline ambiguity and scope growth | No complete demo | D0 first; F1 target tracked separately; defer commercial/dialogue extensions until baseline evidence |
